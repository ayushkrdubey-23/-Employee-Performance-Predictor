### Additional Graphs to Create Manually (for README)

Create these using the EDA notebook or a simple script and save to `images/`:

| Graph | Description | Code Approach |
|-------|-------------|---------------|
| Performance rating distribution | Count plot of High/Medium/Low | `sns.countplot(data=df, x='performance_rating')` |
| Correlation heatmap | Feature correlations | `sns.heatmap(df.corr(), annot=True)` |
| Training hours by performance | Box plot | `sns.boxplot(data=df, x='performance_rating', y='training_hours')` |
| Attendance rate by performance | Box plot | `sns.boxplot(data=df, x='performance_rating', y='attendance_rate')` |
| Feature importance | Bar chart of top features | `plt.bar(features, importances)` |

## How to Take Screenshots (Windows)

### Using Snipping Tool (Recommended)
1. Press `Win + Shift + S`
2. Select the area you want to capture
3. The screenshot copies to clipboard
4. Paste into Paint or directly save as `.png`
5. Save to `images/` folder with the naming convention above

### Using Print Screen
1. Press `PrtScn` for full screen, or `Alt + PrtScn` for active window
2. Open Paint, paste (`Ctrl + V`)
3. Crop if needed, save as `.png`

### Using VS Code
1. Open the file you want to screenshot
2. Use the built-in preview for Markdown/CSV
3. Capture with Snipping Tool
